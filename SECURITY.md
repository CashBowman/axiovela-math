# Security policy

## Supported versions

Security fixes target the newest source on `main` and, when practical, the newest downloadable beta. Older prereleases may require upgrading.

## Report a vulnerability privately

Use GitHub's **Security** tab and open a private repository security advisory. Please do not disclose a suspected vulnerability in a public issue, discussion, screenshot, log, or pull request.

Include the affected version and platform, the smallest safe reproduction, expected impact, and any suggested mitigation. Remove API keys, provider credentials, private research, personal paths, and other unrelated data.

You should receive an initial acknowledgement within seven days. A fix and disclosure timeline depends on severity, reproducibility, and platform-signing requirements.

## Security boundaries

Axiovela Math runs local tools and user-selected AI providers. Full-access provider modes may execute commands and modify project files; use the narrowest access level that fits the task. Provider requests may transmit selected project context and incur provider charges.

Formal checks do not establish that an informal claim is true, novel, or represented by the formal statement. Treat imported web content, model output, and experiment observations as untrusted until reviewed.
