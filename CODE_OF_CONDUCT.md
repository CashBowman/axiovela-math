# Code of conduct

We want participation in Axiovela Math to be constructive, precise, and welcoming.

Be respectful, critique ideas rather than people, give actionable technical feedback, and make room for different backgrounds and levels of experience. Harassment, threats, discriminatory conduct, sexualized attention, deliberate intimidation, and publication of another person's private information are not acceptable.

Maintainers may edit or remove contributions and restrict participation when behavior undermines a safe, productive project. Report conduct concerns privately through the maintainer's GitHub profile or a private security advisory when the report also involves a security or privacy issue. Reports will be reviewed as promptly and confidentially as practical.

This policy applies in repository spaces and in public spaces when someone is representing the project.
