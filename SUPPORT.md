# Support

For installation problems, reproducible bugs, and focused feature requests, [open an issue](https://github.com/CashBowman/axiovela-math/issues/new) using the template.

Include the Axiovela Math version, operating system and architecture, steps to reproduce, and the exact error. Remove API keys, provider sessions, private research, personal paths, and unrelated logs or screenshots.

Use a private [security advisory](SECURITY.md) for vulnerabilities. Mathematical correctness, novelty, provider availability, model quality, and successful formalization are not guaranteed support outcomes.
